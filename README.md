# ENOUGH ALREADY! YOU'RE READY NOW. — Landing Page

A responsive static landing page for SOAR Leadership Solutions.

## Files

- `index.html` — page structure and approved event copy
- `styles.css` — responsive design system and visual styling
- `script.js` — mobile navigation and subtle scroll reveals
- `assets/katina-hero.webp` — approved Katina hero photograph
- `assets/katina-portrait.webp` — approved Katina about-section photograph
- `assets/soar-leadership-solutions-logo.webp` — original SOAR logo, cropped only to remove unused transparent canvas

## Preview

Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
